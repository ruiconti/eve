The Discord channel can now answer DMs, mentions, and thread replies. `discordChannel({ gateway: {} })` accepts messages forwarded from the Discord Gateway, and `runDiscordGatewayRelay` from the new `eve/channels/discord/gateway` entry point holds that connection, for example in a Vercel Daemon. In text channels, a mention starts a conversation and a reply to the bot continues it; return `conversation` from `gateway.onMessage` to group messages differently, or `startThread` (or set `gateway.startThread`) to answer in a new thread. `defaultDiscordMessageAuth` gives a message's author the same principal `defaultDiscordAuth` gives them for commands and button presses. Default Discord auth now identifies a person as `discord:<userId>` with issuer `discord` everywhere, instead of scoping server principals to the guild, so their connected accounts and approvals follow them between DMs and servers. Existing server-scoped principals, such as connected accounts and pending approvals, do not carry over.
